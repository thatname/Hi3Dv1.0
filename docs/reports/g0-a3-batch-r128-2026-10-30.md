# G0 A3：R128 几何拟合批量结果（2026-10-30）

## 范围与决策

固定 `manifest-balanced50.json` 的 50 个资产全部进入 A3：20 个拓扑闭合候选（其中 8 个多连通、A0 符号语义待复核）及 30 个非闭合 mesh。A0 的 `candidate` / `needs_review` / `excluded_nonclosed` **仅表示 A0 有符号欧氏基准的资格**，不筛掉 A3 资产；每条 A3 结果保留原 A0 标志和 concerns。尚无人工 A0 符号批准，A3 成功不改变 A0 资格。

本轮 A3 从 A2 的共同支撑及配对场开始，使用固定版 vae3d 的 `refine(..., steps=30, samples=8192, mode='joint', max_deformation=0.5)`。R128、相位 0.5；场值和 delta 都以细体素为单位。A2 和 A3 都经 vae3d classic MC 提取、还原到输入 mesh 的原坐标，再以同一组原 mesh、4096 点/方向、bbox 对角线 0.5% 和 1% 阈值评估；不清理、简化或重新归一化提取结果。此表的 A2 是 **A2_classic**，不能直接与早先 A1/A2 批量报告的 Lewiner 提取指标混用。

## 验证证据

批量成功 **50/50，失败 0**。回读 50 份 `target.npz`、配置、审计及原始 mesh：坐标、cells 和 cell_indices 与 A2 逐元素一致；场值的负号和精确零值均未变化；全体场/delta 有限；最大单轴位移 0.5 细体素；无倒置 cell 或倒置穿越 cell。A0 标志计数为 12 `candidate`、8 `needs_review`、30 `excluded_nonclosed`，与输入一致。逐资产处理时间总和约 288.2 秒；记录的最大 PyTorch 已分配显存约 647 MiB，不含 CUDA/Kaolin/进程其他显存，不能作为完整峰值显存结论。GPU 数值检查及正式拟合均实测完成；未执行多 GPU 等价性或网络训练。

|---|---:|---:|---:|---:|---:|
| 全部 | 50 | 0.08209 → 0.07651 | 39/50 | 0.94487 → 0.95941 | 0.96734 → 0.97337 |

Chamfer 是输入 mesh 原坐标单位，受资产尺度和少数难例影响；逐资产平均差为 -0.00558，中位差 -0.000193。仍有 **11/50** 个资产 Chamfer 回退，最大回退来自清单 index 14（+0.00420）；最大改善来自 index 7（-0.11558）。上述结果说明本批次的几何拟合通常改善提取几何，但不是每件资产都改善，也不能单凭本对照声称优化场等于严格欧氏 SDF、A0 符号可靠或 VAE 训练收益。
