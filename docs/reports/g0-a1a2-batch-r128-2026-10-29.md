# G0 A1/A2 固定 50 资产批量基线（2026-10-29）

验证类型：远端真实 mesh 的 CPU 目标生成、缓存一致性检查及原坐标系 raw mesh 几何评测。A0 人工真值、A3/A4、VAE 训练和 GPU 性能不在本轮结果内。

## 固定协议

- 输入：`/data/hi3d/g0-prep/manifest-balanced50.json` 与 `mesh-load-balanced50.json`，20 个拓扑闭合候选加 30 个非闭合资产；不改写源 mesh，不替换失败样本。每个主文件按 manifest 的 SHA-256/字节数核对。
- 参考实现：vae3d commit `422e79988ccda06ef0995bf7768cd05a8894a124`。R=128，中心点采样偏移 0.5，CPU 射线与 CPU 距离；同一次查询导出 A1（UE50 投票）和 A2（门控背壳）。共同支撑取两个阶段近表面与符号交叉单元的并集，膨胀两层，再补齐完整 cells。各阶段独立缓存场值、`[s,delta]`、支撑、原坐标 raw mesh 和审计。未清理、简化、过滤组件或重新归一化提取 mesh。
- 提取器固定为 `skimage.measure.marching_cubes`（Lewiner）。该协议内部的 A1/A2 可比；与 vae3d classic MC 或后续 A3/A4 比较时须先统一提取器，并单列算法差异。
- 几何指标：对源 mesh 和各阶段 raw mesh 分别按三角面积，用固定随机种子 `20261029` 在表面每方向采样 4096 点；用 Open3D CPU 最近三角形查询双向欧氏距离。Chamfer-L1 为两个方向平均距离的均值；法向一致性为两方向最近面法向绝对点积的均值。F-score 阈值为**各资产源 mesh 原坐标包围盒对角线**的 0.5% 和 1%，同时保存 precision、recall 与实际阈值。记录原坐标 raw mesh 面数、边界边、非流形边和 watertight。指标是抽样估计，不能将小幅差异直接解释为稳定质量收益。
- 运行根目录：`/data/hi3d/g0-prep/g0-a1a2-r128-cpu-v1/`。`plan.json` 固定 manifest、加载审计、代码哈希、后端与评测参数；`assets/NN.json` 逐资产持久化成功/失败、耗时、缓存和指标；`summary.json` 始终保留全部 50 个资产的成功、失败、待处理分母，按闭合候选/非闭合分组汇总。入口可恢复已有成功项，已有完整缓存但评测失败时可重试评测。

运行命令（环境缓存与临时目录均位于 `/data/hi3d/g0-prep/`）：

```bash
cd /data/hi3d/g0-prep
TMPDIR=/data/hi3d/g0-prep/tmp \
XDG_CACHE_HOME=/data/hi3d/g0-prep/cache \
PYTHONPATH=/data/hi3d/g0-prep/vendor-full:/data/hi3d/g0-prep/vae3d:/data/hi3d/g0-prep \
/data/hi3d/hi3d-validation/.venv/bin/python -m experiments.vae_sdf.run_initial_batch \
  --manifest /data/hi3d/g0-prep/manifest-balanced50.json \
  --load-audit /data/hi3d/g0-prep/mesh-load-balanced50.json \
  --vae3d-root /data/hi3d/g0-prep/vae3d \
  --output-root /data/hi3d/g0-prep/g0-a1a2-r128-cpu-v1 \
  --resolution 128 --samples 4096
```

实际先在同一运行根目录用相同命令附加 `--max-assets 1` 预检首个资产，再运行上面的完整命令；入口跳过已成功项，因此首个资产没有重复生成。未使用 `--verify-reference` 重复计算全部 50 个 A2，单资产逐元素参考对照沿用早期 smoke 证据。

## 结果

**50/50 成功，0 失败，0 待处理。** 闭合候选 20/20、非闭合 30/30 均有 A1/A2 两套缓存、缓存回读和原坐标 raw mesh 指标；两阶段均无空 mesh。50 个资产中 37 个初始场至少有一个采样值改变，29 个 A2 增加了负值采样点。以下按资产分别计算，再对资产求平均/中位数；Chamfer 用各自源 mesh 包围盒对角线归一化后汇总，越低越好。F-score 和法向一致性越高越好。

| 子集 | 指标 | A1 平均 | A2 平均 | A1 中位数 | A2 中位数 | A2 更好 / 更差 / 持平 |
|---|---|---:|---:|---:|---:|---:|
| 全部 50 | Chamfer / 源 bbox 对角线 | 0.000874 | 0.000802 | 0.000373 | 0.000373 | 14 / 20 / 16 |
| 全部 50 | F-score 0.5% | 0.96884 | 0.96677 | 0.98884 | 0.98996 | 9 / 11 / 30 |
| 全部 50 | F-score 1% | 0.98316 | 0.98491 | 0.99786 | 0.99792 | 11 / 7 / 32 |
| 全部 50 | 法向一致性 | 0.94487 | 0.94506 | 0.95627 | 0.95649 | 13 / 20 / 17 |
| 闭合候选 20 | Chamfer / 源 bbox 对角线 | 0.000322 | 0.000325 | 0.000206 | 0.000206 | 3 / 6 / 11 |
| 非闭合 30 | Chamfer / 源 bbox 对角线 | 0.001242 | 0.001119 | 0.000611 | 0.000641 | 11 / 14 / 5 |

全体的 Chamfer 平均下降由少数资产影响，逐资产比较中 A2 更差的有 20 个、优于 A1 的有 14 个，不能据此宣称背壳整体提升质量。0.5% F-score 均值略降，1% 阈值均值略升，说明结论对评测阈值敏感。A2 的 5 个 raw mesh 出现边界边，全部在非闭合子集；A1 没有出现边界边，两阶段均未检测到非流形边。提取 mesh 的闭合性与**源 mesh 是否闭合**不同，不能把 A1 结果当作 A0 实体真值。

逐资产处理时间合计 1128.4 秒，单资产中位数 19.8 秒，最长 92.2 秒（另一个为 83.8 秒）；包含加载、目标生成、缓存校验与双阶段评测，不是纯 UE50 查询时间。运行根目录占用约 1.3 GiB。资产按顺序在 CPU 后端处理，此记录不能外推为 GPU 性能。

可复核产物：`summary.json` SHA-256 `c37b490de4213311ebf9b48826359fd135220f85a71e9f40fc94d90e6b68259a`；`plan.json` SHA-256 `177cb288682261ec4b6ce18f4ec9d25d6ec6d0a5bc205d3578eb9f208347bb0b`。`analysis.json` 是由完整 `summary.json` 派生的尺度归一化及配对汇总，SHA-256 `e1cf6f527dee60c0611e084446dbb812747bcefce9398e08dd159a20ef063824`。可用以下命令重算，不重新查询 mesh：

```bash
PYTHONPATH=/data/hi3d/g0-prep \
/data/hi3d/hi3d-validation/.venv/bin/python -m experiments.vae_sdf.analyze_initial_batch \
  --summary /data/hi3d/g0-prep/g0-a1a2-r128-cpu-v1/summary.json \
  --output /data/hi3d/g0-prep/g0-a1a2-r128-cpu-v1/analysis.json
```

此结果只完成 R128 CPU 的 A1/A2 目标表示基线。A0 需人工确认可靠符号；A3/A4 仍需实现。多视角轮廓/深度、薄结构专项、不同提取器对照以及更高分辨率/后端不包含在本轮。先前的参考实现逐元素核对另见 [A1/A2 小样本记录](g0-a1a2-initial-smoke-2026-10-29.md)。
